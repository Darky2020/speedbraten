API

Read-only JSON for the hub's players, the boards and the records.

/api/v1/ base path GET only CORS open cached 10 s per URL, online 2 s 5 req/s per address, bursts of 20
/online/boards/board/records/runs/players/player

Conventions

Runs whose replay is public carry replay, the URL to download the signed replay (a .sbr file to open in the client's replay browser or race as a ghost); it is absent while a new record's replay is still held back.

Times come as ms (a number of milliseconds) and time (the same as m:ss.mmm). Dates (when) are RFC 3339 in UTC: when the witness judged the run.

A player is a player's id, the same as in the address of their page (/player?id=…). Names can change and aren't unique; ids don't.

Errors are {"error": "…"} with 400 for a missing or bad parameter, 404 for no such board or player, 405 for a method other than GET, 429 past the rate limit (with Retry-After: 1) and 500.

Kinds and modes

A board is one map in one mode for one kind of run. Objects that name a board carry map, kind, mode and mode_name (the mode as text).

flagruntake the enemy flag and score it: 11 ctf, 12 insta ctf, 17 effic ctf
racestart to finish on a race map: always 0, since runs in ffa and in coop edit share one board per map (mode_name is "ffa or coop edit"); a race board asked for with mode 1 answers as mode 0
campaigna singleplayer campaign, all its maps in one run: the negative singleplayer modes

GET/api/v1/online

Who is on the hub now, and what each player is doing.

Response

  • onlineboolfalse while the hub hasn't been heard from for a few minutes; the list is then empty
  • countnumberplayers with a name
  • playerslistby name
    • namestring
    • statestringmenu, playing (a map, untimed) or run (a timed run)
    • mapstringthe map they have loaded
    • modenumber
    • kindstringempty when it isn't a flagrun, race or campaign
    • lobbynumber0 for none; players with the same number play together
    • hoststringthe lobby's host
    • spectatingstringwho they watch, empty when not spectating
    • awaystringdnd, afk or empty

Example

{{jsonhl `{"online":true,"count":1,"players":[{"name":"alice","state":"run","map":"forge","mode":17,"kind":"flagrun","lobby":4,"host":"alice","spectating":"","away":""}]}`}}

GET/api/v1/boards

Every board with at least one witnessed run, most entries first.

Parameters

kind optionalonly this kind: flagrun, race or campaign
mode optionalonly this mode number

Response: a list of

  • map, kind, mode, mode_namethe board
  • entriesnumberplayers on it
  • recordobjectits best run
    • playerstring
    • namestring
    • msnumber
    • timestring
    • whenstring
    • runnumber
    • replaystringdownload URL, once public

Example

{{jsonhl `[{"map":"forge","kind":"flagrun","mode":11,"mode_name":"ctf","entries":3,"record":{"player":"4f1c9e…","name":"bob","ms":8650,"time":"0:08.650","when":"2026-11-08T22:47:14Z","run":7,"replay":"https://speedbraten.example/replay?run=7"}}]`}}

GET/api/v1/board

One board's leaderboard: every player's best run, fastest first, and its legacy record. A flagrun board with only a legacy record answers with no entries; a board with neither is 404.

Parameters

map requiredthe map's name
kind requiredflagrun, race or campaign
mode requiredthe mode number

Response

  • map, kind, mode, mode_namethe board
  • entrieslistfastest first
    • ranknumberequal times share a rank
    • playerstring
    • namestring
    • msnumber
    • timestring
    • whenstring
    • runnumberthe run's id
    • replaystringdownload URL of the signed replay; absent until it is public
  • legacyobject or nullthe best time from before the witness, not witnessed
    • playerstringthe name the source gives
    • msnumber
    • timestring
    • datestringas the source gives it, may be empty
    • sourcestring
    • linkstringmay be empty

Example

{{jsonhl `{"map":"forge","kind":"flagrun","mode":11,"mode_name":"ctf","entries":[{"rank":1,"player":"4f1c9e…","name":"bob","ms":8650,"time":"0:08.650","when":"2026-11-08T22:47:14Z","run":7,"replay":"https://speedbraten.example/replay?run=7"}],"legacy":{"player":"Rex","ms":8410,"time":"0:08.410","date":"2019-04-02","source":"flagruns.com","link":""}}`}}

GET/api/v1/records

Records as they were set, newest first: every time a board's best was beaten.

Parameters

kind optionalonly this kind
mode optionalonly this mode number
limit optionalhow many: 50 by default, at most 500
latest optional1: only each board's newest record

Response: a list of

  • map, kind, mode, mode_namethe board
  • playerstring
  • namestring
  • msnumber
  • timestring
  • prev_msnumberthe record it beat, -1 for a board's first
  • whenstring
  • runnumber
  • replaystringdownload URL, once public

Example

{{jsonhl `[{"map":"abbey","kind":"flagrun","mode":12,"mode_name":"insta ctf","player":"4f1c9e…","name":"carol","ms":7100,"time":"0:07.100","prev_ms":7400,"when":"2026-11-08T22:47:16Z","run":9,"replay":"https://speedbraten.example/replay?run=9"}]`}}

GET/api/v1/runs

The newest runs that count, newest first: every witnessed run that was valid, not only records and personal bests.

Parameters

kind optionalonly this kind
mode optionalonly this mode number
player optionalonly this player's runs (an id)
limit optionalhow many: 50 by default, at most 500

Response: a list of

  • map, kind, mode, mode_namethe board
  • playerstring
  • namestring
  • msnumber
  • timestring
  • whenstring
  • runnumber
  • recordboolit was the board's best when it was judged
  • replaystringdownload URL while the run is a board entry and public

Example

{{jsonhl `[{"map":"forge","kind":"flagrun","mode":17,"mode_name":"effic ctf","player":"4f1c9e…","name":"bob","ms":9120,"time":"0:09.120","when":"2026-11-09T10:02:41Z","run":231,"record":false}]`}}

GET/api/v1/players

Every player with a run that counts, and their stats.

Parameters

sort optionalrecords (default: most records, then seconds, thirds and boards), runs, recent (newest run first) or name
limit optionalhow many: 100 by default, at most 1000

Response: a list of

  • idstring
  • namestring
  • registeredboolthe name is their hub name or was picked for them, not just the one in their replays
  • statsobject
    • runsnumberruns that count
    • boardsnumberboards they have a time on
    • recordsnumberboards they hold the record on
    • podiumsnumbertop-3 places
    • gold, silver, bronzenumberfirst, second and third places
    • first_run, last_runstringwhen their first and newest runs were judged
    • completionlistper category, as on their page
      • categorystringrace, ctf, ictf, ectf or sp (campaigns)
      • labelstring
      • donenumberboards of the category they have a time on
      • ofnumberthe category's boards: every flagrun map in each mode, every campaign, every race map
      • percentnumberrounded down

Example

{{jsonhl `[{"id":"4f1c9e…","name":"carol","registered":true,"stats":{"runs":393,"boards":41,"records":12,"podiums":25,"gold":12,"silver":8,"bronze":5,"first_run":"2026-10-12T18:20:05Z","last_run":"2026-11-09T09:58:13Z","completion":[{"category":"race","label":"Races","done":6,"of":24,"percent":25},{"category":"ectf","label":"effic ctf","done":30,"of":58,"percent":51}]}}]`}}

Response

  • namestring
  • statsobject

    • boardsnumberboards they have a time on
    • recordsnumberboards they hold the record on
    • podiumsnumbertop-3 places
    • gold, silver, bronzenumberfirst, second and third places
    • first_run, last_runstringwhen their first and newest runs were judged
    • completionlistper category, as on their page
      • categorystringrace, ctf, ictf, ectf or sp (campaigns)
      • labelstring
      • donenumberboards of the category they have a time on
      • ofnumberthe category's boards: every flagrun map in each mode, every campaign, every race map
      • percentnumberrounded down
  • placeslist
    • map, kind, mode, mode_namethe board
    • ranknumber
    • ofnumberplayers on the board
    • msnumbertheir best run
    • timestring
    • whenstring
    • runnumber
