API

read-only JSON for the hub's players, the boards and the records

Basics

  • Every endpoint is a GET under /api/v1/ and answers application/json. Other methods get 405.
  • CORS is open (Access-Control-Allow-Origin: *): pages on any site can call it from the browser.
  • Answers are cached for 10 seconds per URL (/api/v1/online: 2 seconds), so asking more often brings nothing new.
  • Each address can make 5 requests a second on average, in bursts of up to 20. Beyond that the answer is 429 with Retry-After: 1.
  • Errors are {"error": "…"} with status 400 (a missing or bad parameter), 404 (no such board or player) or 500.
  • Times are given twice: ms, milliseconds as a number, and time, the same as text (m:ss.mmm). Dates (when) are RFC 3339 in UTC, when the witness judged the run.
  • A player is a player's id: the same as in the address of their page, /player?id=…. Names can change and aren't unique; ids don't.

Boards, kinds and modes

A board is one map in one mode for one kind of run: map + kind + mode.

kindwhatmodes
flagruntake the enemy flag and score it11 ctf, 12 insta ctf, 17 effic ctf
racefrom the start to the finish on a race map0 ffa or 1 coop edit, the modes races are played in
campaigna singleplayer campaign, all its maps in one runnegative: the singleplayer modes

Each object that names a board has map, kind, mode and mode_name (the mode as text, e.g. "effic ctf").

GET /api/v1/online

Who is on the hub now. No parameters.

fieldtype
onlineboolfalse while the hub hasn't been heard from for a few minutes; then the list is empty
countnumberplayers with a name on the hub
players[]listone per player, by name:
  namestring
  statestringmenu, playing (a map, not timed) or run (a timed run)
  map, mode, kindstring, number, stringwhat they have loaded; kind is empty when it isn't a flagrun, race or campaign
  lobbynumberthe lobby they are in, 0 for none; players with the same number play together
  hoststringthe lobby's host, empty without a lobby
  spectatingstringthe player they are watching, empty when not spectating
  awaystringdnd (do not disturb), afk (no input for a while) or empty
{"online": true, "count": 1, "players": [{"name": "alice", "state": "run", "map": "forge", "mode": 17,
  "kind": "flagrun", "lobby": 4, "host": "alice", "spectating": "", "away": ""}]}

GET /api/v1/boards

Every board with at least one witnessed run, most entries first.

parameter
kindoptional: only this kind (flagrun, race, campaign)
modeoptional: only this mode number

A list of:

fieldtype
map, kind, mode, mode_namethe board
entriesnumberplayers on it
recordobjectplayer, name, ms, time, when of the best run
[{"map": "forge", "kind": "flagrun", "mode": 11, "mode_name": "ctf", "entries": 3,
  "record": {"player": "4f1c…", "name": "bob", "ms": 8650, "time": "0:08.650", "when": "2026-11-08T22:47:14Z"}}]

GET /api/v1/board

One board's leaderboard, every player's best run, fastest first.

parameter
maprequired
kindrequired
moderequired, a number
fieldtype
map, kind, mode, mode_namethe board
entries[]listfastest first:
  ranknumberequal times share a rank
  player, namestring
  ms, time, whenthe run
  runnumberthe run's id
  replaystringwhere to download the signed replay, a path on this site; left out while the replay isn't public yet
legacyobject or nullthe best known time from before the witness, not witnessed: player, ms, time, date (as the source gives it, may be empty), source, link

A flagrun map whose board has no witnessed run yet but a legacy record answers with empty entries; a board with neither is 404.

{"map": "forge", "kind": "flagrun", "mode": 11, "mode_name": "ctf",
  "entries": [{"rank": 1, "player": "4f1c…", "name": "bob", "ms": 8650, "time": "0:08.650",
               "when": "2026-11-08T22:47:14Z", "run": 7, "replay": "/replay?run=7"}],
  "legacy": null}

GET /api/v1/records

Records as they were set, newest first: every time a board's best was beaten.

parameter
kind, modeoptional filters, as for boards
limitoptional: how many, 50 by default, at most 500
latestoptional: 1 keeps only each board's newest record
fieldtype
map, kind, mode, mode_namethe board
player, name, ms, time, when, runthe record run
prev_msnumberthe record it beat, -1 for a board's first
[{"map": "abbey", "kind": "flagrun", "mode": 12, "mode_name": "insta ctf", "player": "4f1c…", "name": "carol",
  "ms": 7100, "time": "0:07.100", "prev_ms": 7400, "when": "2026-11-08T22:47:16Z", "run": 9}]
